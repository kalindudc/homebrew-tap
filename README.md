# kalindudc/homebrew-tap

Homebrew formulae for [cortex](https://github.com/kalindudc/cortex), a local task tracker for supervising several AI coding agents at once.

```bash
brew tap kalindudc/tap             # Homebrew installs only from taps you have added
brew install kalindudc/tap/cortex  # the full name: Homebrew's own cortex is an unrelated project
cortex init
cortex agents install
```

The formula installs the `cortex` CLI on macOS and Linux; upgrade it with `brew upgrade kalindudc/tap/cortex`. For the desktop app of the same version, see [Install](https://github.com/kalindudc/cortex#install) in the cortex README. cortex's release workflow updates the formula; do not edit it by hand.
