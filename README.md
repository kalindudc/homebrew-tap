# kalindudc/homebrew-tap

Homebrew formulae for [cortex](https://github.com/kalindudc/cortex), a local task tracker for supervising several AI coding agents at once.

```bash
brew install kalindudc/tap/cortex
cortex init
cortex agents install
```

The formula installs the `cortex` CLI on macOS and Linux. The desktop app comes with the [install script](https://github.com/kalindudc/cortex#install) or from the [releases page](https://github.com/kalindudc/cortex/releases). The formula is updated by cortex's release workflow; do not edit it by hand.
